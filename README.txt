How to play:
1. Open index.html in a browser.
2. Press START GAME.
3. Swipe on the game board or use the arrow buttons/keyboard.
4. Eat the red food to grow.
5. The snake wraps around all four edges.
6. Touching your own body ends the game.

No libraries or frameworks are required.
